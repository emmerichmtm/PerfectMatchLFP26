2Weights

1 = minor, 10 = decisive. Each weight is the exponent of that criterion's desirability in the overall product.

Desirability scales and hard rules

Harrington desirability: the "just acceptable" value scores 50 %, the "fully satisfactory" value 80 %.

3Must-haves

Proposed from each person's own words. Check them, edit or remove; proposed rules apply until you change them.

Load the survey to see the must-haves.

4Locked and forbidden pairs

Set from the pairs table. Applied in the next computation.

    Match internationals with local friends

    1. Load the survey export, or try the fictional example.
    2. Interact: set the weights and check each person's must-have on the left.
    3. Compute: every international gets a partner if the rules allow it; the lowest pair is raised as far as possible.
    4. Review grades, constraints and each pair. Lock good pairs, forbid unsuitable ones, adjust rules.
    5. Iterate until satisfied, then save result.csv and report.txt.

    Grades: 1 insufficient · 2 barely satisfying · 3 ok / solid · 4 very good · 5 perfect.
